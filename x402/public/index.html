Payment Vault
Stellar Testnet

Pay-per-request USDC that lands in a contract, not a hot wallet.

This server sells one API response for 0.001 USDC using the x402 payment protocol. Every payment settles straight into a Soroban vault contract. Only the owner can withdraw, and anyone can keep the vault's storage alive without being able to touch the funds.

Try a paid request

  1. The server asks for payment (HTTP 402).
  2. A capped demo wallet signs a 0.001 USDC payment.
  3. The payment settles into the vault and the API answers (HTTP 200).

Rules enforced by the contract

Owner-only withdrawals

Withdrawals require the owner's signature. A non-owner attempt fails on-chain (see the record above).

Allowlisted deposits

Only approved token contracts can be deposited. The owner controls the allowlist.

Permissionless keep-alive

A weekly job from a separate account extends storage TTL. It cannot move funds.
